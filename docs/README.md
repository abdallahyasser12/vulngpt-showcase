# VulnGPT documentation

Browse the [searchable public documentation library](https://showcase.novaseclabs.com/docs/) or read the Markdown source in this directory.

This documentation describes the public product direction, conceptual testing approach, evidence principles, and enterprise evaluation topics for VulnGPT.

VulnGPT is a NovaSecLabs product in private beta. These documents are public product and evaluation material—not a representation that every described capability is generally available, independently audited, or contractually committed.

## Reading these documents accurately

We distinguish between:

1. **Publicly stated product direction:** what VulnGPT is being designed to investigate.
2. **Private-beta availability:** capabilities and limits that may depend on the current evaluation environment and must be confirmed.
3. **Verified external assurance:** certifications, independent audits, customer references, or benchmark results supported by evidence suitable for publication.

Do not infer the third category from the first two. For current commercial, technical, or contractual details, contact NovaSecLabs through its [official website](https://www.novaseclabs.com).
