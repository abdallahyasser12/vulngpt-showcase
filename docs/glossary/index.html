Application Security Glossary

Plain definitions of BOLA, IDOR, actor, invariant, tenant isolation, WAF and other terms used across the VulnGPT documentation.

2 min readLast updated 31 Oct 2026View source on GitHub

This glossary explains terms used throughout the VulnGPT public documentation. Definitions are intentionally practical and scoped to application-security testing.

TermMeaning
ActorA user, service, or identity performing an application action.
AuthorizationThe decision about whether an authenticated or identified actor may perform a particular action on a resource.
AuthenticationThe process of establishing or verifying an identity.
BOLABroken Object Level Authorization: an access-control failure in which an actor can access an object they should not be permitted to access.
Business logic flawA weakness in the rules, assumptions, or workflow constraints governing application operations.
Control caseA known-good comparison used to interpret a test result.
EvidenceObservable information that supports or weakens a security hypothesis.
FalsificationTesting an alternative explanation or attempting to disprove a hypothesis rather than only seeking confirmation.
Ground truthA documented expected result for a test scenario, established independently of the system's result being evaluated.
HypothesisA specific, testable statement about a possible security failure.
IDORInsecure Direct Object Reference: a common pattern associated with object-level authorization failures, where changing or supplying a reference can expose an access-control weakness.
InvariantA security or business rule that should remain true across relevant actors, objects, actions, and state transitions.
Multi-actor testingA test design that compares behavior across multiple authorized identities or roles.
Object ownershipThe user, tenant, or business entity to which an application resource belongs.
RetestA follow-up assessment of the same security expectation after a proposed remediation.
SessionThe application context that associates multiple requests with an authenticated or otherwise identified actor.
State transitionA change from one application or workflow state to another.
Tenant isolationThe separation of data and operations belonging to different customer organizations or tenants.
WAFWeb Application Firewall: an intermediary security control that inspects or filters application traffic. A WAF response is not, by itself, proof of the application's underlying security behavior.
