Find the flaws that hide in behavior.

VulnGPT is designed to run autonomous penetration tests on web applications you are authorized to test. It compares what different identities can do inside the scope you set, then keeps the evidence for you to review.

A response is a clue, not proof.

A request can return 200 and still be a vulnerability. Another can return 403 and hide one. What matters is who asked, what they own, and what changed.

What a payload scanner sees

Each request on its own. Both return 200 with valid JSON and no error text. Nothing looks malformed, so nothing is flagged.

What behavior-aware testing compares

The same invoice, requested by its owner and by a different account. If both get the body, the access rule is the question. VulnGPT is designed to turn that into a testable hypothesis, then check it against a control.

The evidence standard

A finding is a claim with its proof attached.

A result should say what was expected, what was tried, what was seen and what is still unknown. The standard behind VulnGPT is public, including the cases where a response proves nothing.

CASE FILE · INVOICE ACCESSIllustrative example
Hypothesis
Invoice 1042 belongs to Identity A. Identity B, on a different account, should be denied.
Controlled test
Request the invoice as A to set the control. Request the same invoice as B. Change nothing else, then repeat to check the result is stable.
Observed
In this example B receives the full invoice body, matching the control, on both attempts.
Limitations
One object, two test identities, one environment. It shows this path is open, not that every path is. Caching, WAF responses and expired sessions are listed as alternative explanations to rule out.

Autonomy, defined

What autonomous means for VulnGPT

Autonomous means VulnGPT plans and runs the test steps itself inside the target, scope, and runtime budget you authorize; it does not mean unsupervised: you verify the target, set scope, confirm authorization, and review the evidence.

What VulnGPT does not do

  • It does not test what you have not authorized.You verify the target, set the scope and confirm authorization before a run.
  • It does not promise full coverage.It reports what a run reached with the identities and budget you gave it. No finding is not proof of no flaw.
  • It does not replace expert judgment.A person decides impact, priority and the fix.
  • It publishes no detection or false-positive rates.VulnGPT is in private beta, and internal testing is not independent certification.
