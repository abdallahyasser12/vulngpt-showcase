# Support and Contact

This repository provides the public VulnGPT showcase website and supporting documentation.

## Product access

VulnGPT is in private beta. Use the [NovaSecLabs private-beta application](https://www.novaseclabs.com/waitlist) to request access.

## Product and company questions

For general product, partnership, or company information, start at the [NovaSecLabs website](https://www.novaseclabs.com).

Do not include credentials, API keys, session tokens, customer records, private infrastructure details, or vulnerability proof-of-concept material in general inquiries.

## Showcase website and documentation issues

Use the repository's issue forms for reproducible problems with the public showcase website or documentation. Include the affected page, browser/device context where relevant, expected behavior, and sanitized screenshots.

## Security reports

Do not use a public issue for a vulnerability report. Follow the private process in [SECURITY.md](SECURITY.md) and contact **hello@novaseclabs.com** with sensitive details appropriately redacted.

No public support SLA, security bounty, or guaranteed response time is stated here. Any contractual support commitment must be agreed separately.
